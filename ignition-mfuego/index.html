Modelado

Muestra entrenamiento y validación

# Separación en conjuntos de entrenamiento y test
train <- PI_df %>% sample_frac(.8)
test <- PI_df %>% anti_join(train %>% st_drop_geometry()) 

# Convertimos la variable dependiente a binaria (0 = ausencia, 1 = presencia)
train_logit <- train%>% 
  mutate(y=case_when(ignition=="x0"~0,
                     ignition=="x1"~1)) %>% 
  select(-ignition) %>% st_drop_geometry()

test_logit <- test%>% 
  mutate(y=case_when(ignition=="x0"~0,
                     ignition=="x1"~1)) %>% 
  select(-ignition)

Independencia

Los residuos no deben tener autocorrelación espacial ni temporal.

e.g.: Temperatura

  • No hace falta medirla en un transecto cada metro ni cada segundo..

En nuestro caso concreto. Al ser un modelo estatico en el tiempo no se viola la aunción de independencia espacial. No obstante, vamos a validar que se cumpla la asunción de independencia espacial.

Autocorrelación espacial

I de moran

\[ I = \frac{N}{W} \cdot \frac{\sum_{i}\sum_{j} w_{ij}(x_i - \bar{x})(x_j - \bar{x})} {\sum_{i}(x_i - \bar{x})^2} \]

where:

  • \(N\): number of spatial units

  • \(x_i\) value of the variable at location \(i\)

  • \(\bar{x}\): mean of the variable

  • \(w_{i,j}\): spatial weight between locations \(i\) and \(j\)

  • $W = _i _j w_{i,j}$

Como se evalua:

Hipótesis Descripción Interpretación
\(H_0\) No hay autocorrelación espacial Distribución aleatoria
\(H_1\) Hay autocorrelación espacial Agregaciones espaciales (+ o -)

Si \(pvalor>0.05\) No se rechaza \(H_0\),

Si \(pvalor<0.05\) se rechaza \(H_0\) y se acepta \(H_1\)

dist_preds_inv = 1/dist_preds
diag(dist_preds_inv) <- 0
